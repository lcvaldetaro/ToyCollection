# Über Gepetto Toy Database Manager

Der **Gepetto Toy Database Manager** ist eine Anwendung zur Katalogisierung, Verfolgung und Organisation von Spielzeugsammlungen.

## Hauptfunktionen

- **Kategorisierte Erfassung**: Unterstützung für Modellbausätze, Modelleisenbahnen, Slotcars, Standmodelle und benutzerdefinierte Kategorien.
- **Detaillierte Inventare**: Verwaltung von Herstellergeschichten, Modellabmessungen/Maßstäben, Zuständen, Bildern und Notizen.
- **Portabilität**: Import und Export strukturierter JSON-Standarddateien zur datenbankübergreifenden Synchronisierung.
- **Cloud- & Netzwerksynchronisation**: Synchronisieren von Bildern, Datensätzen und statischen Webseiten über SFTP oder Web-Synchronisation.
