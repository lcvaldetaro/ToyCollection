Proteggi i dati della tua collezione con backup completi dell'archivio.

### Backup della collezione
- Salva l'intera collezione — tutti i giocattoli, produttori, categorie e foto — in un unico file `.zip`.
- Conserva questo file in un luogo sicuro, ad esempio su un'unità USB, un disco esterno o nel cloud.

### Ripristina collezione
- Ripristina la collezione da un file di backup `.zip`.
- **Nota**: Il ripristino sostituisce tutti i giocattoli, produttori, categorie e foto attuali su questo dispositivo con i dati del backup.
