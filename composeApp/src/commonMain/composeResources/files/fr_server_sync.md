Synchronisez votre collection sur plusieurs appareils à l'aide d'un serveur privé.

### Fonctions de synchronisation
- **Téléverser vers le cloud** : Envoie les nouveaux jouets, fabricants et photos mis à jour vers votre serveur.
- **Télécharger depuis le cloud** : Récupère les mises à jour depuis votre serveur vers cet appareil.
- **Tester la connexion** : Vérifie que l'application peut se connecter à votre serveur avant le transfert.

### Paramètres
- **Adresse et port du serveur** : L'adresse internet et le port (généralement 22) de votre serveur.
- **Nom d'utilisateur et mot de passe** : Vos identifiants de connexion au serveur.
- **Dossier distant** : Le dossier sur le serveur où les fichiers de la collection sont stockés.
- **URL de base du site web** : Adresse web facultative où votre catalogue en ligne est hébergé.
