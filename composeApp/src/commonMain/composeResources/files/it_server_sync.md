Sincronizza la tua collezione su più dispositivi utilizzando un server privato.

### Funzioni di sincronizzazione
- **Carica sul cloud**: Invia giocattoli, produttori e foto nuovi o aggiornati al tuo server.
- **Scarica dal cloud**: Recupera gli aggiornamenti dal server su questo dispositivo.
- **Verifica connessione**: Controlla che l'applicazione possa connettersi al server prima del trasferimento.

### Impostazioni
- **Indirizzo e porta del server**: L'indirizzo internet e la porta (di solito 22) del tuo server.
- **Nome utente e password**: Le tue credenziali di accesso al server.
- **Cartella remota**: La cartella sul server in cui sono archiviati i file della collezione.
- **URL base del sito web**: Indirizzo web opzionale in cui è ospitato il catalogo online.
