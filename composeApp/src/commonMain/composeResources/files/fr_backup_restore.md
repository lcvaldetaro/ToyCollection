Protégez les données de votre collection avec des sauvegardes complètes en archive.

### Sauvegarder la collection
- Enregistre toute votre collection — tous les jouets, fabricants, catégories et photos — dans un seul fichier `.zip`.
- Conservez ce fichier dans un endroit sûr, comme une clé USB ou un stockage en ligne.

### Restaurer la collection
- Restaure votre collection à partir d'un fichier de sauvegarde `.zip`.
- **Remarque** : La restauration remplace tous les jouets, fabricants, catégories et photos actuels sur cet appareil par le contenu de la sauvegarde.

Stockage des données et synchronisation dans le navigateur web.

### Stockage du navigateur
- Les modifications de votre collection sont enregistrées directement dans ce navigateur web.
- La sauvegarde et la restauration de fichiers (`.zip`) ne sont pas disponibles dans la version web.
- Pour mettre à jour votre collection avec les données d'autres appareils, utilisez l'onglet **Synchronisation du serveur**.
