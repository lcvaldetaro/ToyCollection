Organisez vos jouets en groupes personnalisés.

### Gérer les catégories
- **Ajouter une catégorie** : Appuyez sur **Ajouter une catégorie** pour créer un nouveau groupe (comme Maquettes, Modèles réduits, Trains ou Circuits routiers).
- **Titre d'affichage** : Le titre affiché sur l'écran de la catégorie et dans le menu de navigation.
- **Icône** : Choisissez un symbole visuel pour la catégorie dans la barre de navigation.
- **Préfixe photo** : Un court préfixe (par exemple `kit_` ou `car_`) pour identifier les photos de cette catégorie.
- **Modifier et supprimer** : Modifiez les détails à tout moment ou supprimez les catégories inutilisées.
