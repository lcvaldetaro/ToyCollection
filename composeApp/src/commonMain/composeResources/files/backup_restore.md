Safeguard your collection data and create web pages.

### Back Up Collection
- Saves your entire collection — all toys, makers, categories, and photos — into a single `.zip` file.
- Store this file in a safe place, such as an external drive or cloud storage.

### Restore Collection
- Restores your collection from a backup `.zip` file.
- **Note**: Restoring replaces all current toys, makers, categories, and photos on this device with the backup contents.

### Create Website Pages
- Generates web pages (`.html`) of your catalog in your storage folder.
- You can open and view your collection in any web browser without running the app.
