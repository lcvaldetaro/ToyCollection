Safeguard your collection data with full archive backups.

### Back Up Collection
- Saves your entire collection — all toys, makers, categories, and photos — into a single `.zip` file.
- Keep this backup file in a safe place, such as a USB flash drive, external drive, or cloud storage.

### Restore Collection
- Restores your collection from a backup `.zip` file.
- **Note**: Restoring replaces all current toys, makers, categories, and photos on this device with the contents of the backup file.

Data storage and synchronization in the web browser.

### Browser Storage
- Your collection changes are saved directly in this web browser.
- File backup and restore (`.zip`) is not available in the web version.
- To update your collection with changes from other devices, use the **Server Sync** tab.
