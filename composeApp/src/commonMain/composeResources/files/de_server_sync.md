Synchronisieren Sie Ihre Sammlung über einen privaten Server auf mehreren Geräten.

### Synchronisierungsfunktionen
- **In die Cloud hochladen**: Sendet neue und geänderte Spielzeuge, Hersteller und Fotos an Ihren Server.
- **Aus der Cloud herunterladen**: Lädt Aktualisierungen von Ihrem Server auf dieses Gerät herunter.
- **Verbindung testen**: Prüft die Verbindung zum Server vor der Dateiübertragung.

### Einstellungen
- **Serveradresse & Port**: Die Internetadresse und Portnummer (normalerweise 22) Ihres Servers.
- **Benutzername & Passwort**: Ihre Zugangsdaten für den Server.
- **Entfernter Ordner**: Der Ordner auf dem Server, in dem Sammlungsdateien gespeichert werden.
- **Website-Basis-URL**: Optionale Internetadresse, unter der Ihre Katalog-Website gehostet wird.
